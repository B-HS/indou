<h1 align="center">Indou</h1>

<p align="center">A fast, modern macOS window switcher — a free AltTab alternative for macOS 26.</p>

## Features

- **Custom shortcuts** — record any modifier + key, with multiple trigger profiles
- **Every real window** — across Spaces & displays, including minimized and fullscreen
- **Grid navigation** — Tab to cycle, arrows / vim keys to roam, release to focus
- **In-switcher actions** — close, minimize, fullscreen, quit; drag-select for bulk
- **Search** — fuzzy matching + Korean initial-consonant (초성)
- **Smooth & quiet** — toggleable animations, localized (English / 한국어 / 日本語)
